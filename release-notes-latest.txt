■ 버그 수정
• [P1] Q111 오채점 — D열 중첩 괄호 [[p],[d]] 파싱 오류 수정
  (학생이 'P'만 써도 만점 처리되던 문제 해결)

• [P2] Q102/104 유형 오분류 — 3단어 구문을 리스트로 오인하던 기준 수정
  Type C 판정 기준을 5항목 이상으로 상향, 순서 강제 매칭 올바르게 적용

• [P3] Q108/110 단어 오탈자 미인정 — 4자 단어(wabe, gyre 등) 편집거리 허용
  엄격 모드 기준 '≤4자 완전일치' → '≤3자 완전일치'로 수정

• [P4] Q109 중복 항목 오답 처리 — "frumious frumious ..." 중복 시 0점 방지
  이미 매칭된 토큰의 재출현은 무시(오답 카운트 제외)

• [P5] Q108 항목 수 오산정 — 11항목/10항목 혼재 시 10/11점 처리 수정
  기준 항목 수를 가장 짧은 허용 form 기준으로 설정

• [P6] 실패 임계값 정책 추가
  오답+누락 ≥ N개이면 0점 처리하는 failCutoff 부분점수 정책 추가

• Type A / Type C 스펠링 오류 허용 설정 분리
• Type A 오탈자 편집거리 1 상한 고정 (round(배점÷3) 부분점수, 33% 프리셋 추가)
