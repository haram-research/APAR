Type A — 단답/구 정답형 단답형
APAR 가이드 / 문제 유형별 작성 방법
감지 조건 & 채점 특징
Type A는 단답/구 정답형 문제입니다. 쉼표 구분 항목이 4개 이하, 단어 수가 4개 이하인 경우 자동 감지됩니다.
감지 조건
쉼표 구분 항목 ≤ 4개
단어 수 ≤ 4개
대소문자·괄호·공백 차이 무시
예: (genetically)(determined)(specialization) → 정답 처리
오탈자 허용
기본 비활성. 활성 시 편집거리 1만 부분점수 인정
정답키 작성 예시
Type A
// 단일 정답 [genetically determined specialization] // 복수 정답 (OR 조건) [genetically determined specialization][GDS] // 여러 형식 허용 [deep structure][심층구조][deep-structure]
올바른 예시
[genetically determined specialization]
피해야 할 형식
[genetically, determined, specialization]
주의: 3–4단어짜리 고정 구(fixed phrase)는 쉼표 없이 작성하세요.
[genetically determined specialization] ← 권장
