Type C — 단어 리스트형 (부분점수 O)
APAR 가이드 / 문제 유형별 작성 방법
감지 조건 & 채점 특징
쉼표로 구분된 항목이 5개 이상인 form이 하나라도 있으면 Type C로 자동 감지됩니다.
순서 무관 매칭
학생이 순서를 바꿔 써도 정답 처리됩니다
부분점수 지원
(맞은 개수 / 전체) × 배점, 반올림
주의사항
• 항목이 4개 이하이면 Type A로 분류됩니다
• 중복 항목 작성 시 두 번째 이후는 자동 무시됩니다
• 오탈자(편집거리 1)는 기본적으로 허용됩니다
Type C 정답키 예시
APAR
// 기본 리스트 형식 [항목1, 항목2, 항목3, 항목4, 항목5, ...] // 복수 허용 표현 (같은 위치에 대안) [brillig, slithy, toves, gyre, gimble, wabe, jaws, time, son, foe] [brillig, slithy, toves, gyre, gimble, wabe, claws, time, son, foe] // 선택적 추가 항목 (보너스) ['Twas, brillig, slithy, toves, gyre, gimble, wabe, jaws, time, son, foe]
순서 무관
학생이 순서를 바꿔 써도 정답으로 인정됩니다
부분점수
(맞은 개수 / 전체) × 배점 계산
복수 허용 표현: 같은 위치에 여러 대안을 허용하려면 두 개의 form을 병기
예) 7번째 위치에서 "jaws" 또는 "claws" 모두 정답
