Type D & E — 번호 선택형 & 문장 서술형
APAR 가이드 / 문제 유형별 작성 방법
Type D — 번호 선택형
숫자·공백·쉼표·괄호로만 구성
감지 조건
모든 form이 숫자·공백·쉼표·괄호로만 구성되어야 합니다.
권장 형식
// 숫자만 사용 [1, 3, 5]
// 원형 숫자도 가능 [①, ③, ⑤]
채점 특징
숫자 집합의 완전 일치만 정답
순서 무관 매칭 ("1, 3, 5" = "5, 3, 1")
"①③⑤" 형태도 정답 처리
주의: 숫자 외 문자가 포함되면 Type E로 분류됩니다.
Type E — 문장 서술형
단어 수 5개 이상인 form
감지 조건
단어 수가 5개 이상인 form이 하나라도 있으면 Type E로 분류됩니다.
권장 형식
// 완전한 서술 문장
[언어는 인간에게 고유한 능력이다]
채점 특징
문장 전체를 Levenshtein 유사도로 비교
30% 이하 편집거리 → 부분점수 + 검토 권장
복잡한 서술형은 LLM 보조 사용 권장
권장: 5단어 이하 문장은 Type A로 작성하세요.
